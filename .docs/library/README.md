## 💡 What This Folder Is For

Learning material for anyone new to the vault, or to the tools it runs on, such
as git, GitHub and Markdown. Nothing here is binding: what the vault requires
is in the rest of `.docs/` and in each folder's `README.md`, and the standards
it follows are in the
[Standards Index](https://github.com/tannergolden/standards/blob/Development/docs/README.md).

- **Guides**: how to do something with the vault or its tools, step by step.
- **Background**: the ideas a newcomer needs, explained once.
- **Further reading**: the sources worth keeping, each with a line on why.

It is not the vault's `Library/`, the reference collection of what is learned
about the world, which `Library/README.md` keeps by its own rules: this folder
holds only guides to the repository and its tools.

The template ships nothing here but this README, which 🔄 Template Sync keeps
current in a vault. A page you add here is **yours from the first commit**:
nothing upstream ever writes, moves or removes it. The log below is redrawn
from the files the folder holds.
