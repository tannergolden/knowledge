## Retention Policy

| Entry Type | Retention | Action |
|------------|-----------|--------|
| Tools and software in use | While the project runs | Kept |
| Tools tried and abandoned | Until abandoned | Flagged for removal: no need to track dead ends here |
| Reference links still useful | While the project runs | Kept |
| Reference links no longer relevant | Until stale | Flagged for removal when a link is clearly outdated or unused |
| Books and articles | While the project runs | Kept: reading history is useful context |
| Assets and files | While the project runs | Kept, with their locations updated when files move |
| People and contacts | While the project runs | Kept: relationships outlast individual tasks |
| Entire file | Kept when the project closes | Kept with the folder |

**How this file is kept:** Resources.md is a reference shelf, kept current and accurate. An abandoned tool and a link that is no longer relevant are flagged for removal; books, articles, people and active assets stay for the life of the project. When a file moves or a URL changes, its entry is updated rather than duplicated. When the project closes, the file is kept with the rest of the folder. The policy flags; the owner decides.
