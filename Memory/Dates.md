# 📅 Dates

Prospective memory: the future-facing reference for dates that matter. Add entries through the engine - `memory add date <recurring|onetime|milestone> "When" "Event"` - which formats and inserts the row into the right table. A person's significant dates also live in their `Entities/People/` entry. Small enough to stay one file; split only if it ever crosses the size threshold.
