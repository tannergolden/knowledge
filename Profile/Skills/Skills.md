# 🛠️ Skills

What the user is competent at, and - most usefully for the AI - **how much to explain in each domain**. Calibrating explanation depth to expertise matters because detailed guidance written for a novice becomes redundant and even counterproductive for an expert (the expertise-reversal effect). Use absolute, per-domain levels, not a single global "smart user" flag. Areas of genuine depth get their own entry; casual interests are `Profile/Preferences/`, not here.
