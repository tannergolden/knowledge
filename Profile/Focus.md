# 🔦 Focus

The deliberate **dynamic** layer of the profile - what is true for the user *right now*. It is the pressure-release valve that lets every other facet stay timeless: anything that changes month to month lives here, not in the stable facets. It changes often, so **trust it over older notes and refresh it whenever you use it**. Boundary: concrete tasks and project execution live in `Projects/`; dated happenings live in `Memory/`; standing long-horizon goals live in `Profile/Goals/`. This holds the user's current orientation, not their work items.

## Snapshot

What the user most needs help with right now. Fill and refresh often.

The handful of things the user is actively focused on this period, the biggest thing on their mind, and what would make this period a success.
