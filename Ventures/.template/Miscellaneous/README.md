# 🗃️ [Company] - Miscellaneous

Anything for [Company] that fits no department yet. It starts empty. Read this README before changing anything in this folder; its rules add to `Ventures/[Company]/README.md`, `Ventures/README.md` and the root `README.md`, and never loosen them.

## What Goes Here

- Files that belong to the venture but to none of its departments, named plainly for what they are.

## Rules

- A file that belongs to a department moves there; once several files here share a subject, a fitting home is proposed for them.
- Nothing personal and nothing general: personal information goes to `Profile/` or `Memory/`, and general knowledge to `Library/`.

## What Goes Elsewhere

- Every department folder beside this one says in its own `README.md` what it holds.
