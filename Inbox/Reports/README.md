# 📑 Reports

The held library for finished reports. Research and discovery reports land here, such as the `research-and-development` skill's, whether for a company the owner runs or for the owner's own questions, and this is where both kinds are kept, by the rules below. Reports are deliverables, held for reference.

## Held, not sorted

Reports live here and stay here. They are not sorted into the BRAIN's permanent layers (the Library, a venture, a project): a report is a working artifact, produced, held, used, and eventually cleared, not durable reference knowledge. The session-start Inbox sweep skips this folder, as it skips the Visuals and Ideas libraries, so a report is never proposed for re-sorting. Reports stay fully linted and cataloged like any other vault file.

## Good for three months, then verify

Every report is good for up to three months from its date. After three months it is stale: before it is used again, it is verified, its findings re-checked to see they still hold, rather than trusted as-is. The window ends on the report's `review_by` date in frontmatter, three months after it was filed, so a stale report shows by that date alone. This one flat rule replaces any per-topic freshness window: all reports, research and discovery alike, expire at three months and are re-verified on demand. A still-valid report confirmed on reuse has its `review_by` moved to three months after the verification.

## This README is the report index

This README is the one hub that links every held report. The index below carries a wikilink to each report in this folder, so the whole library is browsable from here. This index is the **only** place a report is linked: no other file in the BRAIN cites or links to a report, which keeps the wider wikilink graph free of disposable nodes. A report can also be found by searching this folder.

The index is kept in lockstep with the folder. When a report is filed, refreshed, or cleared, its entry below is added, updated, or removed in the same edit, so the index always mirrors what is actually here. A finding that must outlive its report is still promoted into the durable layer in its own right: a `Library/` holding, a folder's `README.md` and its rules, or the root `README.md`.
